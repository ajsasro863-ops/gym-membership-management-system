FITZONE GYM MEMBERSHIP MANAGEMENT SYSTEM

REQUIREMENTS
- Node.js
- Visual Studio Code
- Google Chrome
- Internet connection for npm install

INSTALLATION
1. Open the project folder in VS Code.
2. Open Terminal > New Terminal.
3. Make sure the terminal is inside the folder containing package.json.
4. Run npm install.
5. Wait for the installation to finish.
6. Run npm start.
7. Open Chrome and visit http://localhost:3000.
